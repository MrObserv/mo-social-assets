Quick reference — which file does what

logo-master.svg

Full-detail canonical mark. Use for print, presentations, decks, and any placement ≥80px. This is the source of truth — all other variants derive from it.

logo-on-dark.svg

Primary variant. Use on any dark background (#000 to #1A1A1A). This is what you'll use most — newsletter headers, dark-mode website, presentation slides.

logo-on-light.svg

Deeper tones for light backgrounds (#E0E0E0 to #FFF). Use when the logo needs to sit on a white or light grey surface — print materials, light-mode contexts.

logo-mono.svg

Your most-used file. All-white strokes for watermarks at 30–60% opacity. Every blog thumbnail, every featured card, every carousel slide. Bottom-right, per §24.11.

favicon.svg

Optimised stroke weights for 16–32px rendering. Has CSS prefers-color-scheme dark mode built in. Use for browser tabs via <link rel="icon">.

PNG rasters

Fallbacks for platforms that don't accept SVG. Use favicon-512x512.png for circular-crop profile pics. favicon-192x192.png for YouTube watermark. apple-touch-icon.png for iOS.
