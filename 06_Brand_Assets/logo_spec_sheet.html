Logo Specification — Direction 02 "Evolved"

01 — Scale
Size-optimised variants
Stroke weights adjust at each breakpoint. Below 48px, the middle ring drops and tick strokes thicken. Below 32px, the highlight drops. Each size is tuned for pixel-grid clarity.
160px — Hero
Website, presentation, print
80px — Header
Newsletter, beehiiv logo
48px — Icon
Google search, mobile
32px — Favicon
Browser tab (HiDPI)
16px — Favicon
Browser tab (standard)
02 — Backgrounds
Colour environment testing
The on-dark variant is primary. The on-light variant uses deeper tones (#0a5c5e ring, #0d7377 ticks) for sufficient contrast. Monochrome is for watermarks at 30–60% opacity.
